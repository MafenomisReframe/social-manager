# Social Manager

Prima dashboard demo React + Vite, indipendente dal gestionale Re-Frame.

Avvio: `npm install` e `npm run dev`.

I dati sono dimostrativi. Non sono presenti autenticazione, backend, connessioni social o isolamento multi-tenant reale. Non utilizzare dati personali o credenziali nel prototipo.

Roadmap: autenticazione e permessi; tenant e clienti; calendario e contenuti; chat Segnalazioni; connessioni OAuth; Social Intelligence; Budget AI; Brand Interview; Creative Lab; white-label.
